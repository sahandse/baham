# باهم

اپلیکیشن وب برای ساخت گروه و تماشای فیلم/سریال با دوستان. یک گروه بساز یا با کد یک گروه بپیوند (تا ۸ نفر)، فیلم/سریال انتخاب کن و با هم تماشا کنید.

ساخته‌شده با Next.js (App Router) + TypeScript + Tailwind CSS، رابط کاملاً فارسی و راست‌به‌چپ (RTL).

## اجرا

```bash
npm install
npm run dev
```

روی [http://localhost:3000](http://localhost:3000) باز می‌شود.

## ساختار

- `src/app/page.tsx` — صفحه اصلی (ایجاد گروه / ورود با کد)
- `src/app/create` — فرم ساخت گروه
- `src/app/join` — فرم ورود به گروه با کد
- `src/app/group/[code]` — اتاق گروه: اعضا، انتخاب فیلم/سریال، پخش
- `src/lib/groupStore.ts` — لایه‌ی داده (فعلاً روی `localStorage`، طوری نوشته شده که بعداً به‌راحتی با یک API واقعی جایگزین بشه)

## محدودیت فعلی (مهم)

این نسخه بدون بک‌اند و صرفاً برای نمایش رابط کاربری (UI/UX) ساخته شده. اطلاعات گروه‌ها در `localStorage` مرورگر ذخیره می‌شه، یعنی:

- بین چند **تب** روی یک مرورگر به‌صورت زنده sync می‌شه (برای تست، دو تب باز کن).
- بین دو **دستگاه/مرورگر مختلف** (مثلاً موبایل دو نفر) sync نمی‌شه، چون داده‌ای رد و بدل نمی‌شه.

برای نسخه‌ی واقعی که دوستان از گوشی‌های خودشون به هم وصل بشن، نیاز به یک بک‌اند (مثلاً یک API + دیتابیس + یک لایه real-time مثل WebSocket برای هم‌گام‌سازی پخش) هست. لایه `groupStore.ts` طوری طراحی شده که جایگزین کردنش با فراخوانی API واقعی ساده باشه.

## فونت

از فونت [Vazirmatn](https://github.com/rastikerdar/vazirmatn) (لایسنس آزاد SIL OFL) به‌عنوان جایگزین بصری نزدیک به فونت ایران‌سنس استفاده شده، چون ایران‌سنس لایسنس تجاری داره و قابل embed مستقیم در پروژه نیست. اگر لایسنس ایران‌سنس رو داری، کافیه در `src/app/layout.tsx` فراخوانی `Vazirmatn` از `next/font/google` رو با import فونت خودت جایگزین کنی.
